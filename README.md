# 经营体管理平台

这是一个根据现有经营体平台业务流程重新设计的、可直接运行的交互式原型。它把企业经营数据、知识库、AI 问答、分析流程和经营驾驶舱统一到一个工作台中。

## 已实现模块

- 首页：核心统计、系统资源状态、最近操作
- 多维表格：文件树、记录表格、视图/筛选/排序/分组工具栏、字段类型配置、导入导出
- 模板管理：模板结构预览、从模板创建表格、示例数据与视图复制选项
- 知识库：向量模型、切片大小与重叠、Top-K、相似度阈值、重排和索引流水线
- 文档管理：拖拽上传、目标知识库、自动解析/索引、处理队列和切片统计
- Agent 管理：系统提示词、模型参数、多轮上下文、知识库检索、引用标注和 HyDE
- AI 问答：Agent 切换、历史会话、连续对话、知识库检索状态和引用来源
- 数据分析师：INPUT/LLM/OUTPUT 节点画布、节点参数、模板变量、测试运行和发布入口
- 经营分析：四步驾驶舱向导、业务筛选、经营 KPI、风险预警和 AI 行动建议

## 运行

项目没有第三方依赖，直接打开 `index.html` 即可运行：

```bash
open index.html
```

也可以使用任意静态服务器：

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。

## 数据说明

演示数据初始化在浏览器端，部分新增和删除记录会写入 `localStorage`。配置弹窗、流程画布、问答回复和 AI 洞察用于完整表达业务功能，不会调用真实后端或模型。生产化时建议把数据层替换为 REST/GraphQL API，并增加租户、组织、角色和数据权限。

详细业务分析见 [docs/BUSINESS_ANALYSIS.md](docs/BUSINESS_ANALYSIS.md)。
