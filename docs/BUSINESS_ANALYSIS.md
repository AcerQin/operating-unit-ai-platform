# 经营体管理平台业务分析

## 1. 产品定位

平台不是单一报表系统，而是由四层能力组成的企业经营智能中台：

1. **经营数据底座**：通过多维表格承载销售、回款、订单、设备等结构化业务数据。
2. **企业知识底座**：通过知识库、文档解析、向量化和分块策略管理非结构化知识。
3. **AI 能力层**：将聊天模型、知识库、温度和引用能力组合成面向场景的 Agent。
4. **经营决策层**：通过可编排的数据分析流程和 AI 驾驶舱形成指标、洞察与报告。

## 2. 核心业务闭环

```text
业务数据/企业文档
        ↓
多维表格 + 知识库索引
        ↓
问答 Agent + 数据分析流程
        ↓
经营驾驶舱 + AI 分析报告
        ↓
业务行动、复盘与数据回写
```

## 3. 功能域

### 3.1 多维表格

- 新建空白表格或从模板创建
- 支持文本、数字、日期、选择、人员、附件、公式、评分、进度等字段类型
- 支持视图、搜索、筛选、排序、分组、填色、字段配置和导入导出
- 管理字段显隐、必填、顺序、记录、所有者和更新时间
- 承载销售订单、出货回款、设备台账等业务主题
- 为分析流程提供结构化输入

### 3.2 模板管理

- 按业务分类沉淀表结构
- 支持导入、新增、检索和复用
- 统计字段数、初始化记录数和更新时间

### 3.3 知识库与文档

- 配置向量模型、切片大小、重叠量、分隔符与分块策略
- 配置 Top-K、相似度阈值和重排
- 支持结构感知分块和语义相似度分块
- 文档上传后经历解析、切片、索引生命周期
- 支持详情、重索引、下载和删除

### 3.4 智能体与对话

- Agent 绑定聊天模型和一个或多个知识库
- 配置系统提示词、温度、最大 Tokens、多轮上下文和 HyDE 查询改写
- 温度控制回答稳定性，引用开关保证结果可追溯
- 会话支持查询、置顶、归档、分享和继续对话

### 3.5 数据分析智能体

- 通过节点编排形成“输入 → 处理 → 输出”流程
- 输入节点支持手动输入、文件上传和多表读取，并可限制最大行数
- LLM 节点支持模型、系统提示词、用户提示词和上下游变量
- 输出节点支持 HTML 结果、RustFS 上传和动态文件名
- 支持 PC 与小程序双端发布

### 3.6 经营驾驶舱

- 按营销、生产、财务、人力、采购、仓储、质量、设备、研发分板块
- 通过“基础信息 → 数据表 → AI 配置 → 仪表布局”完成创建
- 每个驾驶舱支持经营体、区域、周期和数据口径筛选
- AI 分析输出核心 KPI、增长亮点、风险预警和行动建议
- 典型主题包括销售分析、三大财务报表分析、设备 TPM

## 4. 建议的生产架构

- 前端：Vue 3/React + TypeScript + ECharts
- API：Spring Boot/FastAPI + OpenAPI
- 主数据：PostgreSQL
- 多维表格：PostgreSQL JSONB 或独立表格引擎
- 向量检索：pgvector/Milvus
- 对象存储：S3/RustFS
- 工作流：DAG 编排服务 + 异步任务队列
- 权限：租户、组织、角色、菜单、字段和行级数据权限
- 审计：登录、查询、模型调用、文档变更、报表发布全链路留痕

## 5. 第一版原型边界

当前仓库提供无依赖、可直接运行的前端原型，主要用于验证信息架构、业务流程和交互。数据保存在浏览器 `localStorage`。接入后端时可以保留页面结构，将数据访问替换为 API。
